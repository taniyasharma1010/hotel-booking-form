# Experiment 4 – Hotel Room Booking Form

A simple hotel room booking form built with HTML.

## Objectives
- Design a hotel room booking form using HTML
- Use input fields to collect user details
- Apply labels for form accessibility
- Implement dropdown menus (`select`) and text areas
- Create buttons for form submission and reset

## Features
- Full Name, Email, Phone inputs
- Check-in / Check-out date pickers
- Room type dropdown
- Number of guests
- Special requests textarea
- **Book Now** button (validates dates and shows the experiment outcome) and **Reset Form** button

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser (or use the Live Server extension in VS Code)

## Outcome
- Successfully created a hotel room booking form webpage using HTML
- Implemented input fields, labels, select, textarea, and buttons
- Learned practical form design techniques for web applications
